# Krithika D — Portfolio Website

A responsive, light-themed personal portfolio built with HTML, CSS, and JavaScript. It presents a combined software-development, AI/QA, and business-analysis profile.

## Preview locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

## Before publishing
- Confirm the work dates and role descriptions, especially the BPCL end date.
- Add a PDF resume and change the header Resume link from `#contact` to the PDF filename (for example `resume.pdf`).
- Replace the portrait placeholder if desired.
- Add direct project repository/demo URLs where available; the current personal-project link points to your GitHub profile.
- Only retain work-project descriptions you are permitted to share publicly.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository named `krithika-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish and show the site URL.

If you name the repository `krithi3502.github.io`, GitHub Pages can use it as your account's root site.

This is a static website; it does not need a backend. Google Fonts requires an internet connection, while the layout and content are local files.
